# Given-name sources

Generated by `scripts/update_given_names.py`; pinned URLs and download SHA-256
checksums are in `sources.json`. Runtime reads local `names.txt` only.

- NEN magazine / mdanina: https://github.com/mdanina/nen-imena-dataset,
  https://n-e-n.ru/imena. CC BY 4.0. Only name, short_forms and
  international_forms are extracted; biographies and descriptions are excluded.
- Solvenium: https://github.com/solvenium/names-dataset. Repository MIT license
  is included. The name lists derive from the Wiktionary Names Appendix:
  https://en.wiktionary.org/wiki/Appendix:Names. Wiktionary text is licensed
  CC BY-SA (https://creativecommons.org/licenses/by-sa/4.0/); treat the derived
  name list under those attribution/share-alike terms, not solely the code license.

Changes: merged first names only, Unicode NFC, removal of whitespace-containing,
non-letter, mixed-script and non-Latin/non-Cyrillic entries, deduplication.
This is a recognition aid, not a complete list or evidence of identity.
