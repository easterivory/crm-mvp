# Повторный /start: памятка для техника

## Настройка

1. Откройте нужную воронку и её черновик.
2. Во вкладке «Настройки воронки» выберите реакцию на повторный /start:
   - «Продолжать»: прежняя логика. На вопросе без обязательных данных /start может продолжить сценарий; возраст, телефон и другие обязательные ответы не обходятся.
   - «Напомнить текущий шаг»: бот повторяет текущий вопрос или текущее сообщение с кнопками, не переходя дальше.
3. При необходимости заполните «Текст перед напоминанием», например «На чём мы остановились? Давайте продолжим». Пустое поле отключает вступление. Язык произвольный.
4. Для исключения выберите блок «Сообщение» или «Вопрос», откройте «Основное» и измените «Реакция на повторный /start». По умолчанию блок наследует настройки воронки.
5. Сохраните и опубликуйте новую версию.

## Что не меняется

- Старые воронки без новых настроек работают в режиме «Продолжать».
- Активные диалоги остаются на своей версии воронки. Публикация не переносит их автоматически на новую версию.
- Напоминание не записывает /start вместо имени, возраста или телефона, не повторяет CRM-действия, интеграции, теги и подачу, не сбрасывает таймеры пушей.
- В блоке из нескольких сообщений повторяется только текущее сообщение, а не весь блок.
- Если текущий вопрос ещё ожидает своей задержки, он придёт по исходному расписанию один раз, без дополнительного вступления и дубля.
- Частые /start ограничены одним напоминанием за 20 секунд на текущем посещении шага.
- Обычный повторный /start не снимает паузу менеджера и не оживляет завершённую воронку.
- В submission-проекте явный /start после 30 дней без сообщений лида по-прежнему запускает актуальную опубликованную воронку заново; это правило приоритетнее напоминания. Самостоятельного перезапуска по таймеру нет.
- Для именных аккаунтов новая настройка не меняет обработку входящих сообщений.

## Проверка после выката

- На старой воронке проверьте свободный вопрос и обязательный возраст/телефон: поведение прежнее.
- На новой версии включите напоминание, остановитесь на вопросе, отправьте /start: вступление и текущий вопрос появляются, ответ всё ещё требуется.
- Проверьте кнопки повторённого сообщения: они ведут по прежним связям.
- На вопросе с задержкой отправьте /start до доставки: вопрос приходит один раз по исходному таймеру.
- Проверьте локальное исключение «Продолжать» и диалог на паузе менеджера.

Изменение хранится в JSON конфигурации версии воронки; новой миграции для напоминания нет.
